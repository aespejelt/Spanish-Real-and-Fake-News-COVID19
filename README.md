# Spanish-Real-and-Fake-News-COVID19
Real and fake Spanish COVID-19 news data set. 

#################################
This database was established by Dr. Angelina Espejel for the study of fake news in Spanish. 
For any questions regarding the dataset or to request permission for its use, please send an email to: angelina.et@gmail.com
The purpose of using this database is purely academic.
This data set is registered as intellectual propertyin INDAUTOR with the number: 03-2024-121113581000-01. 
##################################

This dataset gathers real and fake news collected from social networks such as WhatsApp, Facebook, Instagram, and Telegram to investigate the detection of fake news in Spanish. True stories were validated using official sources and the website verificando.com.

The publication of the results using this data set is in process.
